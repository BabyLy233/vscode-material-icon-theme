# Material Icon Theme for Mayoi

Built from [material-extensions/vscode-material-icon-theme](https://github.com/material-extensions/vscode-material-icon-theme)
at `v5.40.0`. Do not edit this branch by hand: the **Build Mayoi plugin** workflow rewrites it.

## Install

```sh
mayoi plugin install BabyLy233/vscode-material-icon-theme@mayoi
```

Then choose **View → Theme → File Icon Theme… → Material Icon Theme**.
